# Invidious database setup

`init-invidious-db.sh` and `sql/` are Invidious's own database setup, copied unchanged from
[iv-org/invidious](https://github.com/iv-org/invidious) so the player's Postgres can start
on its own. They're under Invidious's license, the AGPL-3.0 ([LICENSE](LICENSE)), not Tamlil's.
